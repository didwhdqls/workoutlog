# 머신로그 — 기구별 운동 기록 앱

같은 "시티드 로우"라도 해머스트렝스 플레이트 머신, 라이프피트니스 핀 머신, 케이블은 무게감이 다릅니다.
머신로그는 **운동(동작) 아래에 기구(브랜드·방식·헬스장)를 따로 두고, 이전 기록·최고 기록·그래프를 기구 단위로만** 보여 주는 운동 기록 앱(PWA)입니다.

## 주요 기능

- **기구별 기록**: 운동마다 브랜드 머신이 미리 등록되어 있음 (예: 시티드 로우 = 케이블 / 해머스트렝스 플레이트 / 라이프피트니스 핀 / 테크노짐 / 싸이벡스 / 매트릭스 / 파나타 / 뉴텍 / 드랙스 / 프라임 / 아틀란티스 / 왓슨 / 짐레코 / 호이스트 / 프리코어). 없는 기구는 운동 중 기구 선택 창에서 브랜드를 검색해 바로 등록.
- **브랜드 52종**: 해머스트렝스, 라이프피트니스, 테크노짐, 싸이벡스, 매트릭스, 프라임, 아틀란티스, 파나타, 짐80, 아스널, 왓슨, 뉴텍, 드랙스, 프리코어, 호이스트, 노틸러스, 짐레코, 스타트랙, 임펄스, 부티빌더, 프리모션, 스포츠아트, 바디솔리드, DHZ, 슈아, 스틸플렉스, 카이저, 로그, 엘레이코, 펄스, 바디톤, 프라이멀, 터프스터프, 레전드, 머슬디, 플렉스피트니스, 네뷸라, 슈넬, BH 피트니스, 조던, 오리진, 엑시고, 짐기어, 컨셉2, 메가매스 (한글/영어 모두 검색).
- **예전 브랜드**: 스트라이브(지금의 프라임), 이카리안(프리코어), 트로터·이글(싸이벡스), 유니버셜(노틸러스), 바디마스터스, 폴라리스. 지금 브랜드 이름으로 검색해도 함께 나오고, 기록은 따로 쌓임.
- **이전 기록은 같은 기구에서만**: 운동 중 "이전" 칸과 회색 힌트는 지금 고른 기구의 지난 기록만 보여 줌.
- **헬스장별 자동 선택**: 헬스장을 정하면 그 헬스장에서 마지막으로 쓴 기구를 자동으로 고름. 처음 가는 헬스장에서는 머신이 섞인 운동은 직접 고르게 해서 기록이 섞이지 않게 함.
- **그립**: 운동마다 뉴트럴·오버핸드·언더핸드·와이드·클로즈·로프·V바 그립을 고를 수 있고, 이전 기록·신기록은 같은 기구·같은 그립끼리만 비교. 다음에 같은 기구를 고르면 지난번 그립이 자동으로 선택됨.
- **기구 세팅 메모**: 시트 높이, 패드 위치 등을 저장해 두면 운동 중 기구를 고를 때 바로 보임.
- **단위**: 기구마다 kg / lb / 칸(핀 번호) 중 선택.
- **루틴(계획)**: 세트·목표 무게·횟수·휴식 시간. 기구를 "운동할 때 고르기"로 두면 헬스장마다 알아서 맞춰짐.
- **휴식 타이머**: 세트 완료 체크 시 자동 시작, ±15초, 종료 시 소리·진동.
- **기록/통계**: 운동한 날에 루틴 이름이나 분할 이름(등, 등&가슴, 상체, 전신 등)이 표시되는 달력(날짜를 누르면 그날 운동만), 홈의 이번 주 7일 달력, 운동 요약, 기구별 최고 무게·추정 1RM·추이 그래프, 기구별 신기록(PR) 표시.
- **통계** (통계 탭): 주간/월간 전환, 총 볼륨·세트·운동 횟수·시간(진행 중인 기간은 지난 기간 같은 날짜까지와 비교), 최근 12주/12개월 추이(볼륨·세트·운동 횟수·운동 시간, 부위별로 걸러 보기, 평균·최고·추세), 부위별 주간 세트 수와 부위·세부 부위별 권장 세트(부족·적정·과다 표시, 운동별 내역). 워밍업 세트 제외, 운동의 주 타깃 부위에만 1세트로 집계. 풀업·딥스 같은 맨몸 운동은 체중 × 횟수, 어시스트 풀업은 (체중 − 보조 무게) × 횟수로 볼륨에 포함 (운동 기록 화면의 "오늘 체중"에 입력, 다음 운동엔 지난 체중이 미리 채워짐). 주 시작 요일(월/일)은 설정에서.
- **기록 수정**: 완료한 운동도 기록 화면의 "수정"에서 이름·날짜·시간·헬스장·운동·기구·세트(무게·횟수·종류)·메모·순서를 고칠 수 있음.
- **운동 돌아보기**: 운동을 마치면 컨디션·집중도·피로도·펌프감·만족도(각 1–5)와 상황 태그(잠 부족, 통증 등), 메모를 남길 수 있음. 기록 목록에 요약이 보이고 나중에 기록 화면에서 고칠 수 있음.
- **백업**: 설정 → JSON 내보내기/가져오기. (데이터는 기기 브라우저에만 저장됨)

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
```

같은 Wi-Fi의 폰에서 확인하려면:

```bash
npm run dev:phone    # 출력되는 Network 주소를 폰 브라우저로 열기
```

## 배포 (폰에 앱처럼 설치)

GitHub Pages로 자동 배포됩니다 (`.github/workflows/deploy.yml`).
`main` 브랜치에 push하면 GitHub가 빌드해서 `https://<아이디>.github.io/<저장소>/`에 올려 줍니다.
진행 상황은 저장소의 **Actions** 탭에서 볼 수 있어요.

처음 한 번만: 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔 두세요.

폰에서 배포 주소를 열고 "홈 화면에 추가"(iOS 사파리 공유 메뉴 / 안드로이드 크롬 메뉴)를 누르면 앱처럼 실행되고 오프라인에서도 열립니다.
새 버전을 올린 뒤에는 앱을 한 번 닫았다 열면 반영됩니다.

로컬에서 배포용 빌드만 확인하려면:

```bash
npm run build        # dist/ 폴더 생성
npm run preview      # 빌드 결과 미리보기
```

## 구조

| 경로 | 내용 |
|---|---|
| `src/data/seed.ts` | 기본 운동·기구 카탈로그. 운동/브랜드를 추가하려면 여기에. **id는 바꾸지 말 것** |
| `src/types.ts` | 데이터 모델 (Exercise → Variant(기구) → 기록) |
| `src/store.ts` | 상태 관리(zustand) + localStorage 저장 |
| `src/lib/stats.ts` | 이전 기록 찾기, 기구 자동 선택, 1RM·PR 계산 |
| `src/pages/ActiveWorkout.tsx` | 운동 기록 화면 |
| `src/pages/Exercises.tsx` | 운동 목록, 기구별 비교, 기구 상세(그래프) |

개발 모드에서는 브라우저 콘솔에서 `__store.getState()`로 데이터를 볼 수 있습니다.
